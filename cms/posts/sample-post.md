This is a sample post, added so the blog and the content manager can be tested. It will be deleted before the blog goes live.

## What you can do in the content manager

- Write a new post and publish it.
- Save a post as a draft, so it stays hidden until you are ready.
- Add a picture, with a short description for people who cannot see it.
- Edit or delete a post at any time.

## What happens when you publish

The website updates by itself within a couple of minutes. There is nothing else to do.
